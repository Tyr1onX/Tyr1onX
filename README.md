## 代表项目

### [PatchPilot](https://github.com/Tyr1onX/patchpilot)

一个由大语言模型辅助的代码修改命令行工具。

主要功能：

- 根据自然语言要求修改指定代码文件
- 支持修改结果预览
- 支持 Diff 差异展示
- 支持 Dry Run，不直接覆盖原文件
- 提供文件路径与参数校验

技术栈：`Node.js` `JavaScript` `LLM API`

---

### [Daily Journal](https://github.com/Tyr1onX/daily-journal-app)

一个用于记录、浏览和管理个人日报的全栈应用。

主要功能：

- 日报创建、编辑、浏览和删除
- 搜索、标签、日期范围筛选与分页
- 本地草稿保存与恢复
- 多页面编辑冲突保护
- JSON 数据导入与导出
- Playwright 端到端测试
- 独立服务器部署

技术栈：`Next.js` `TypeScript` `SQLite` `Playwright`

---

### [Accounting Excel Tool](https://github.com/Tyr1onX/accounting-excel-tool)

一个面向实际会计工作场景的 Excel 自动化工具。

项目目标是将凭证数据自动整理为：

- 明细账
- 科目余额表
- 应收应付统计
- 费用与利润相关报表

技术栈：`Python` `Excel`
