## 项目

### [课刻](https://github.com/Tyr1onX/desktop-course-widget)

**让一天在桌面上缓慢流动。**

Windows 本地桌面课表。从学校教务系统导入课表，在桌面查看当前课程、下一节与完整周课表。无需账号，数据只保存在本机。

### [ChatX](https://github.com/Tyr1onX/ChatX)

**让 ChatGPT 安全地使用你电脑上的本地能力。**

运行在本机后台的本地桥接器。让 ChatGPT 在授权的 Workspace 范围内读取和修改文件、查看 Git、运行程序，并使用独立浏览器。
